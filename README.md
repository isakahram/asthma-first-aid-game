# Рядом — «Астма: что делать, если…»

Интерактивный образовательный квест на русском языке для подростков 11–17 лет. Игрок помогает однокласснику в шести знакомых ситуациях школьного дня.

## Запуск

Требуется Node.js 20.19+ или 22.12+.

```sh
npm ci
npm run dev
```

Dev-сервер доступен на порту 5173 и слушает `0.0.0.0`. Разрешены локальный адрес и домены предпросмотра `*.e2b.app`.

```sh
npm run build    # Проверка TypeScript и production-сборка в dist/
npm run preview  # Локальный просмотр production-сборки
```

Для публикации достаточно статического хостинга: загрузите содержимое `dist/`. Серверная часть, база данных, API-ключи и внешние шрифтовые сервисы не нужны.

## Что реализовано

- Стартовый экран с дисклеймером и обзором шести эпизодов.
- Правила: четыре шага помощи, правильные и неправильные действия.
- Физкультура (кросс), прогулка (цветение), класс (контрольная), перемена (коридор), столовая (запах краски), экскурсия (лестница).
- По три ответа в каждой ситуации: **10 / 5 / 0 баллов**. Позиция лучшего ответа меняется.
- Короткая поддерживающая обратная связь с объяснением «потому что…». При неполном или неверном ответе отмечается более безопасный выбор.
- Защита от повторного начисления баллов; итог из 60 и три диапазона: **0–25**, **26–45**, **46–60**.
- Итоговая памятка, контакты взрослого и экстренных служб, разбор своих ответов, повторное прохождение.
- Памятка доступна с любого экрана и скачивается как UTF-8 TXT, в том числе без прохождения квеста.
- Сохранение прогресса только в `localStorage` браузера (`ryadom-quest-v1`). При недоступном или повреждённом хранилище квест продолжает работать. Персональные данные не запрашиваются и не отправляются.
- Адаптивный интерфейс, закреплённый счётчик баллов, клавиши **1 / 2 / 3**, управление с клавиатуры, фокус на заголовке при переходах, закрытие памятки клавишей **Escape**, поддержка `prefers-reduced-motion`.
- Семь оригинальных AI-иллюстраций в оптимизированном WebP. Шрифт Manrope хранится локально; иконки — Lucide.

## Содержание и ограничения

В квесте нет дозировок, названий препаратов и схем лечения. Основной алгоритм:

**Сообщить взрослому → помочь сесть → не оставлять одного → вызвать помощь.**

Отдельно сказано, что при необходимости срочной помощи звонить нужно сразу, не дожидаясь взрослого. Контакты `103` и `112` обозначены как номера для России; указано, что в ЕС используется `112`, а для других стран нужно использовать местный номер.

Это учебный продукт, а не медицинская инструкция. Перед использованием в образовательной организации рекомендуется редакционная проверка содержания квалифицированным специалистом и адаптация контактов к стране проведения занятия.

## Структура

```text
src/App.tsx          Экраны, переходы, сохранение прогресса, диалог и скачивание памятки
src/data.ts          Все ситуации, ответы, баллы, памятка и диапазоны результата
src/styles.css       Адаптивные стили и состояния интерфейса
public/images/       Оптимизированные иллюстрации
tests/quest.spec.ts  Сквозные и автоматизированные accessibility-проверки
```

## Тестирование

```sh
npx playwright install chromium
npm test
```

16 проверок (десктоп 1440 px и мобильный экран 390 px): все варианты начисления баллов и три результата, полный путь до перезапуска, отсутствие горизонтального переполнения, скачивание памятки, сохранение прогресса, повторный клик, управление с клавиатуры, модальный диалог, повреждённое/недоступное хранилище и автоматические проверки WCAG A/AA через axe на основных экранах.

Для среды с уже установленным Chromium можно задать `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH`; дополнительные флаги передаются JSON-массивом в `PLAYWRIGHT_CHROMIUM_ARGS`. Автоматическая проверка доступности дополняет, но не заменяет ручное тестирование.
