# Рядом — «Астма: что делать, если…» · 20 ситуаций

Иллюстрированный образовательный квест на русском языке для подростков 11–17 лет. Игрок помогает однокласснику Саше в **20 ситуациях**, выбирает из трёх действий и получает **10 / 5 / 0 баллов**. Максимум — **200 баллов**. Без таймера, персональных данных и серверной части.

## Запуск

Требуется Node.js 22.12+.

```sh
npm ci
npm run dev
```

Открыть: **http://localhost:5173/**. Сервер слушает `0.0.0.0`; разрешены localhost и домены предпросмотра `*.e2b.app`.

```sh
npm run build    # TypeScript, production-сборка и проверка всех путей/иллюстраций
npm run preview  # Просмотр production-сборки
```

## Четыре главы

| Глава               | Ситуации                                                                                 |
| ------------------- | ---------------------------------------------------------------------------------------- |
| 01 · Школьный день  | Физкультура (кросс), прогулка (цветение), контрольная, перемена, столовая (запах краски) |
| 02 · Новые места    | Экскурсия (лестница), библиотека, репетиция, школьный автобус, раздевалка                |
| 03 · Друзья рядом   | Школьный двор, дома у друга, робототехника, день рождения, кинотеатр                     |
| 04 · Время помогать | Трибуна стадиона, торговый центр, мастерская, поход, ожидание помощи                     |

На стартовом экране можно посмотреть иллюстрированные карточки любой главы; прохождение последовательное. В каждом эпизоде есть три ответа с разными баллами, короткое поддерживающее объяснение «потому что…» и подсветка более безопасного действия.

### Подсчёт и прогресс

- `SCENARIO_COUNT` и `MAX_SCORE` вычисляются по набору ситуаций; интерфейс не содержит устаревшего ограничения в шесть эпизодов или 60 баллов.
- Интерпретация результата: **0–80**, **81–150**, **151–200**. Границы вычисляются от максимума.
- Повторный клик и нажатия клавиш не начисляют баллы повторно.
- Прогресс хранится локально в `ryadom-quest-v2`. Корректные ответы из версии `ryadom-quest-v1` сохраняются: после старого финала из шести ситуаций квест продолжается с седьмой, без преждевременного итога.
- Повреждённое или недоступное хранилище не ломает приложение. Перезапуск сбрасывает результат.
- Финал содержит все 20 выбранных ответов, чек-лист, контакты помощи, дисклеймер и кнопку «Пройти заново».

### Интерфейс и иллюстрации

Крупные кнопки, закреплённый счётчик, клавиши **1 / 2 / 3**, диалог с памяткой и закрытием по **Escape**, управление фокусом и поддержка `prefers-reduced-motion`. Памятку можно скачать как UTF-8 TXT с любого экрана.

Каждая ситуация имеет свою иллюстрацию: **16 сцен в WebP и 4 оригинальные векторные сцены в SVG**, плюс главная иллюстрация. Шрифт Manrope и все изображения загружаются локально. Лицензии Manrope и Lucide находятся в `public/licenses/`.

## Публикация на GitHub Pages

`vite.config.ts` задаёт **`base: '/'`**. Все картинки, favicon, шрифты и собранные JS/CSS загружаются из корня сайта, включая предзагрузку следующей сцены. Никакая ветка `gh-pages`, отдельный сервер или секретный токен для деплоя не нужны.

### Однократная настройка владельцем

В репозитории открыть **Settings → Pages → Build and deployment → Source → GitHub Actions**:

https://github.com/ryadom-quest/ryadom-quest.github.io/settings/pages

Включение Pages требует прав администратора и разрешения Pages у подключения. Если API возвращает `Resource not accessible by integration (403)`, выбрать источник в веб-интерфейсе владельца или обновить разрешения подключения GitHub в Arena. Передавать токены и пароли не требуется.

### Автоматический workflow

`.github/workflows/pages.yml` запускается при push в `main`, а также проверяет pull requests в `main`. Доступен `workflow_dispatch`.

1. `npm ci`, установка Chromium, TypeScript и production-сборка.
2. Проверка 20 ситуаций, максимума 200, уникальных картинок и путей в `dist/`.
3. Полный набор браузерных тестов на production-сборке для компьютера и телефона.
4. Публикация проверенного артефакта через `actions/upload-pages-artifact` и `actions/deploy-pages`.
5. Проверка публичного HTML, JS/CSS, favicon, всех иллюстраций и метаданных текущего коммита; URL добавляется в итог workflow.

Pull requests только собираются и проверяются, но **не публикуются**. Права `pages: write` и `id-token: write` выданы только отдельной задаче деплоя. Если для окружения `github-pages` заданы ограничения веток, нужно разрешить `main`. После включения Pages или изменения ограничений можно перезапустить упавшую задачу деплоя.

Адрес сайта после успешного деплоя: **https://ryadom-quest.github.io/**. Факт публикации проверяется задачей `Check the live page, metadata, bundles and all illustrations`, а не только существованием этой ссылки.

```sh
npm run verify:deployment -- https://ryadom-quest.github.io/
```

## Тестирование

```sh
npx playwright install chromium
npm test
```

24 проверки в Chromium: десктоп 1440 px и мобильный экран 390 px. Проверяются все 20 эпизодов и 60 вариантов ответов, максимум 200, границы трёх диапазонов, обзор четырёх глав, настоящие ответы всех картинок по Pages-путям, повторное начисление, сохранение/миграция прогресса, корректный номер 20 (не 020), памятка и скачивание, финальный разбор, повторный старт, клавиатура, хранилище и автоматические WCAG A/AA-проверки через axe.

Для проверки production-сборки установить `PLAYWRIGHT_TEST_SERVER=preview`. `PLAYWRIGHT_BASE_URL` позволяет запустить те же проверки на уже работающем сайте. В среде с готовым Chromium поддерживаются `PLAYWRIGHT_CHROMIUM_EXECUTABLE_PATH` и JSON-массив `PLAYWRIGHT_CHROMIUM_ARGS`. Автоматический аудит доступности дополняет, но не заменяет ручное тестирование.

## Содержание и безопасность

В квесте **нет дозировок, названий препаратов и схем лечения**. Только поддержка и алгоритм:

**Сообщить взрослому → помочь сесть → не оставлять одного → вызвать помощь.**

Если нужна срочная помощь, звонить следует сразу, не дожидаясь взрослого. Контакты `103` и `112` обозначены как номера для России; в ЕС используется `112`, в других странах — местный номер экстренной помощи. Иллюстрации спокойные, без пугающих сцен.

Квест не заменяет медицинскую инструкцию, рекомендации врача и обучение первой помощи. Перед использованием в образовательной организации рекомендуется проверить содержание со специалистом и адаптировать контакты к стране проведения занятия.
